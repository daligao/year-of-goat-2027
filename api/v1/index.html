🀄 Open API v1

Free JSON API for Chinese calendar data. No API key. No auth. CORS enabled via GitHub Pages.

FREE NO AUTH CORS OPEN CC BY 4.0

Base URL

https://chinesefortunetools.online/api/v1/

Endpoints

GET /api/v1/chinese-new-year.json CNY dates 2020–2035
yearintegerGregorian year
datestringCNY date (YYYY-MM-DD)
zodiacstringChinese zodiac animal
elementstringFive element (Metal/Water/Wood/Fire/Earth)
lantern_datestringLantern Festival date (15th day)
fetch Python curl
const res = await fetch('https://chinesefortunetools.online/api/v1/chinese-new-year.json'); const data = await res.json(); const cny2027 = data.years.find(y => y.year === 2027); // → { year: 2027, date: "2027-02-06", zodiac: "Goat", element: "Fire", ... }
import urllib.request, json url = "https://chinesefortunetools.online/api/v1/chinese-new-year.json" with urllib.request.urlopen(url) as r: data = json.loads(r.read()) cny2027 = next(y for y in data["years"] if y["year"] == 2027) print(cny2027["date"]) # 2027-02-06
curl https://chinesefortunetools.online/api/v1/chinese-new-year.json | python3 -m json.tool
GET /api/v1/festivals.json 8 major festivals, dates 2025–2028
namestringEnglish festival name
chinesestringChinese name
emojistringRepresentative emoji
datesobject{ "2025": "YYYY-MM-DD", ... }
fetch
const res = await fetch('https://chinesefortunetools.online/api/v1/festivals.json'); const { festivals } = await res.json(); const cny = festivals.find(f => f.name === "Chinese New Year"); console.log(cny.dates["2027"]); // "2027-02-06"
GET /api/v1/zodiac.json 12 zodiac signs with traits and 2027 forecast
fetch
const res = await fetch('https://chinesefortunetools.online/api/v1/zodiac.json'); const { signs } = await res.json(); const goat = signs.find(s => s.name === "Goat"); console.log(goat.traits, goat.lucky_numbers);
GET /api/v1/lucky-numbers.json Lucky and unlucky numbers by zodiac
fetch
const res = await fetch('https://chinesefortunetools.online/api/v1/lucky-numbers.json'); const data = await res.json(); // data.by_zodiac["Goat"] → { lucky: [...], unlucky: [...] } // data.universal_lucky → [6, 8, 9]
GET /api/v1/gift-taboos.json 10 Chinese gift-giving taboos with severity
itemstringThe taboo gift item
reasonstringWhy it is taboo
severitystringhigh / medium / low
alternativesarraySuggested safe alternatives
fetch Python
const res = await fetch('https://chinesefortunetools.online/api/v1/gift-taboos.json'); const { taboos } = await res.json(); const highRisk = taboos.filter(t => t.severity === "high"); // → clocks, pears, shoes, umbrellas, green hats
import urllib.request, json url = "https://chinesefortunetools.online/api/v1/gift-taboos.json" with urllib.request.urlopen(url) as r: taboos = json.loads(r.read())["taboos"] print([t["item"] for t in taboos if t["severity"] == "high"])
